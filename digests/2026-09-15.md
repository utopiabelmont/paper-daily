## 1. 基于先验信息的二维纳米尺度物体超分辨光学计量（Prior-information based super-resolution optical metrology of 2D nanoscale objects）

- **作者**：Jin-Kyu So、Eng Aik Chan、Carolina Rendón-Barraza、Giorgio Adamo、Nikolay I. Zheludev
- **arXiv 链接**：https://arxiv.org/abs/2609.12671 ｜ 分类：physics.optics ｜ 日期：2026-09-11（new）｜ 相关度：9
- **摘要**：已有工作证明，对狭缝宽度这类**一维**物体做光学计量时，用同类物体的先验信息去训练估计器可以显著提高精度；本文要回答的是这条路线能否推广到**二维亚波长物体的多参数同时测量**。方法是单次曝光采集纳米椭圆颗粒的衍射图样，交给一个神经网络估计器同时反解长轴、短轴与面内取向，该网络用一批尺寸与取向各异的纳米椭圆先验数据训练；同时用**费舍尔信息流（Fisher-information flow）分析**去优化测量装置的物理参数，使测量精度最大化，而不是凭经验搭光路。实验用 633 nm 激光，尺寸测量精度做到 λ/128（即 4.9 nm），取向精度 5°。这篇是今日与本方向重合度最高的一篇：它把"**衍射图样 + 先验训练 + 信息论指导的装置设计**"做成了一条可复用的亚波长尺寸反演范式，与边缘定位/亚像素测量里"用物理正演模型约束学习式估计器"的思路完全同源，其中费舍尔信息流用于**指导硬件参数选型**这一手法尤其值得借鉴。

## 2. TileNet：面向无人机自主平屋面巡检的分块 CNN-SVM 架构（TileNet: Tile-Based CNN-SVM Architecture for Autonomous Unmanned Aerial Systems Inspection of Flat Roofs）

- **作者**：Samuel Dunthorne、Hashim A. Hashim
- **arXiv 链接**：https://arxiv.org/abs/2609.13013 ｜ 分类：cs.CV ｜ 日期：2026-09-11（new）｜ 相关度：6
- **摘要**：平屋面缺陷若不及时发现会带来保温失效、受潮霉变等连锁损失，但人工上房排查既慢又危险，而机载算力与功耗的硬约束又让大模型无法直接搬到无人机上。本文提出一套实时无人机深度学习巡检框架：飞行上采用**双高度多分辨率航线**，高空覆盖大尺度结构问题、低空捕捉细小缺陷；算法上采用**分块（tile-based）架构 + 轻量 CNN-SVM 分类器**（5 个卷积层 + 4 个全连接层，最后一层换成线性 SVM 头）以满足低时延机载推理。在图片级划分的数据集（训练 43,383、验证 3,869、测试 2,540 张切块增强图）上，三个随机种子的平均测试准确率 94.4%（95% 置信区间 ±0.4%），优于 GoogLeNet 的 89.2% 与 AlexNet 的 79.8%；DJI Matrice 350 RTK 实地采集的影像验证了系统可用性。对工业检测有用的两点是：**用"大图切块 + 小模型"替代"大图 + 大模型"来换取边缘端实时性**，以及**用 SVM 头替换 softmax 头**在小样本缺陷类别上的稳定性收益。

## 4. 融合 3D 磁共振影像与临床数据的可解释多模态阿尔茨海默病诊断框架（A Multimodal Explainable Deep Learning Framework for Alzheimer's Disease Diagnosis using 3D Magnetic Resonance Imaging and Clinical Data）

- **作者**：Yusuf Brima、Marcellin Atemkeng、Lakshmana Rao Namamula、Antoine Vacavant
- **arXiv 链接**：https://arxiv.org/abs/2609.12410 ｜ 分类：cs.CV ｜ 日期：2026-09-11（new）｜ 相关度：5
- **摘要**：多模态深度学习可以把影像与临床表格数据结合起来诊断阿尔茨海默病，但"它给出的**解释**在不同模态、不同融合策略、不同人群队列之间是否稳定"一直没人系统查过。作者用 3D CNN 编码 T1 加权 MRI、用前馈网络编码标准化后的临床与人口学数据，在 ADNI 的 6,479 条内部记录与 OASIS-3 的 1,703 条独立记录上，对三分类与两两分类任务比较多种模型配置。结果颇为反直觉：ADNI 上**纯表格模型**三分类 AUC-ROC 最高（0.879），交叉注意力只在 MCI vs AD 上最好（0.861）；而 OASIS-3 上反过来是**纯影像模型**最好（0.910），**没有任何一种融合策略能跨任务跨队列稳定胜过单模态**。解释层面，SHAP 与积分梯度都把 MMSE 认定为最主要的表格特征、两队列全局特征排序高度一致（ρ=0.94 / 0.96），但基于 CAM 的影像解释会随模型配置与队列而变。结论是可解释性必须**在分布漂移下评测**，不能当作模型固有的稳定属性——这一条对任何要跨产线、跨批次部署的工业检测模型同样成立。

## 5. 用 CNN-DNN 架构做并行训练以加速诊断模型开发（Parallel Training Using a CNN-DNN Architecture for Accelerated Development of Diagnostic Models）

- **作者**：Janine Weber-Hamacher、Astha Jaiswal、Philipp Fervers、Dorotya Móré、Athanasios Giannakis、Ricarda Fischbach
- **arXiv 链接**：https://arxiv.org/abs/2609.12902 ｜ 分类：cs.CV ｜ 日期：2026-09-11（new）｜ 相关度：5
- **摘要**：当数据集极大或疫情期间病例数据动态增长时，深度模型的训练效率本身成为瓶颈，需要一种天然支持并行的网络组织方式。作者收集德国三个中心的 300 例 COVID-19 与非 COVID 肺炎 CT，提出基于**图像分解与局部化**的混合 CNN-DNN 模型：把体数据切成子域（如 4×4×1、4×4×2），每个子域独立训练一个局部 CNN，再由一个 DNN 把局部预测聚合成患者级判断，于是子域模型之间可以完全并行。总计训练了 3 种架构下的 156 个模型，汇聚成 12 个患者级诊断模型。最好的结果来自 DenseNet121 + 4×4×1 子域（训练 88.78% / 验证 76.67% / 测试 76.03%）与 3D CNN + 4×4×1 子域（87.72% / 76.82% / 74.86%）；并行训练时间的最大缩减出现在 3D CNN + 4×4×2 子域，达 **31 倍**。需要注意的是训练与测试准确率之间约 12 个百分点的落差说明过拟合仍在，真正的卖点是"**空间分解式并行**"这一训练组织范式，对大幅面在位测量中"整幅图太大、按视场分块各训一模型再聚合"的场景可直接对照。

- **摘要**：可穿戴设备做压力与情感状态识别时，大量研究只比拼分类准确率，却说不清**究竟是呼吸的哪一种性质**把不同状态区分开的。本文用 WESAD 数据集的胸部呼吸通道，在 60 秒窗口、留一被试交叉验证下并行两条支路：直接吃原始波形的紧凑一维 CNN，以及按物理含义分组的手工呼吸签名（呼吸时序、逐次呼吸变异性、波形统计量、频谱/时频描述子、自相关与非线性可预测性描述子），并新引入**自相关转换滞后 Zpm/Zmp** 作为呼吸相关尺度的可解释标志。结果呈现清晰的分工：压力 vs 静息任务上原始信号 CNN 最强（准确率 96.72%、macro-F1 95.30%、MCC 90.61%），而基线、愉悦、冥想这几种非压力状态上紧凑特征模型反而更好（冥想 MCC 88.65%）。作者还诚实地报告了一项**方法学自查**——对 Top-20 特征筛选做严格嵌套重分析后，平均 MCC 从 85.45% 降到 82.29%，说明原流程存在轻微的选择乐观偏差。本篇领域与本方向不重合，但"**特征筛选必须放进嵌套交叉验证内部、否则指标会系统性虚高**"这条教训对所有小样本检测任务通用。

## 7. 用于引力波探测器退相干抑制的路径简并量子干涉术（Path-Degenerate Quantum Interferometry for Decoherence Mitigation in Gravitational-Wave Detectors）

- **作者**：Jonas Rittmeyer、Niels Boettner、Farid Khalili、Mikhail Korobko、Roman Schnabel
- **arXiv 链接**：https://arxiv.org/abs/2609.12204 ｜ 分类：physics.optics ｜ 日期：2026-09-10（cross）｜ 相关度：4
- **摘要**：光学退相干会破坏压缩态光场的量子关联，严重限制引力波探测器的量子非破坏（QND）测量灵敏度，而现有补救方案又要额外加滤波腔、辅助参量放大器和法拉第隔离器——这些子系统本身带来的**空间模式失配**又成了新的退相干源。本文提出**路径简并量子干涉**方案，其核心思路是通过光路的"合并与精简"直接免掉上述整组光学子系统，从而大幅降低模式失配，同时把长期停留在理论层面的**变分读出（variational output）**天然集成进来，以进一步深入 QND 区间。实验上作者验证了该方案的一项核心特性：实现了**保持散粒噪声水平的信号增强**，直接对抗读出损耗的有害影响。由此在不增加任何新元件的前提下改善了信噪比，为下一代 LIGO 升级提供了一条高度优化的量子噪声抑制路线。对精密测量的通用启示是：**减少元件数本身就是一种降噪手段**，当附加子系统的失配损耗超过它带来的收益时，做减法优于做加法。

- **arXiv 链接**：https://arxiv.org/abs/2604.19203 ｜ 分类：physics.optics ｜ 日期：原始提交 2026-04-21，本次为 2026-09-14 公告的修订版（replace-cross）｜ 相关度：4
- **摘要**：半导体器件的散热管理必须从热源处着手，而长期以来一条默认假设是：只要热源尺寸大于主要载热子（声子）的平均自由程，**热源与实际发热斑就重合在同一位置**。本文证明这条"热局域性"范式在**数微米**的长度尺度上就会失效，出现违反傅里叶定律的非局域加热。实验做法是制备横向结构化的半导体薄膜（界面数量逐级增加），用紧聚焦激光加热，再用**拉曼测温（Raman thermometry）**逐点测绘晶格温度分布。最引人注目的结果是：非局域加热的幅度**可以超过激光诱导的局域加热本身**，作者将其归因于远高于低温区间仍然存在的**弹道声子输运**。这对在位光学测量是一个不容忽视的提醒：凡是依赖"激光作用点即温升点"假设去做热补偿或热漂移建模的测量方案（尤其是激光加工在线监测），在微米级空间分辨下这个假设可能根本不成立。

## 11. PLSP（前置阈限空间刻画）：用 OOD 预测取代 OOD 检测的前瞻式模型可靠性方法（PLSP (Pre-hoc Liminal Space Profiling): OOD Prediction over Detection -- An Anticipatory Approach for Machine Learning Model Reliability）

- **arXiv 链接**：https://arxiv.org/abs/2609.12225 ｜ 分类：cs.CV ｜ 日期：2026-09-10（cross）｜ 相关度：4
- **摘要**：分布外（OOD）数据是模型部署失效的主要威胁，而现有 OOD 方法**清一色是事后（post-hoc）的**——都要等到推理阶段，靠准确率、AUC-ROC 等指标的偏移去间接察觉模型已经遇上了 OOD 数据。本文把范式从"OOD 检测"推前到"**OOD 预测**"，提出前置（pre-hoc）框架 PLSP，主要贡献有三：提出与数据集无关的**可信度分数 CREDS** 作为 OOD 预测指标；引入**可信度曲线**来刻画一个模型所能达到的最大可信度；引入**可信度热图与曲面下体积**来表征模型在不同数据集上的前置行为。多数据集实验表明该指标能有效衡量并改善模型面向 OOD 预测的鲁棒性。对产线部署的意义在于：它试图回答"**这个模型在换料换批次之后还靠不靠得住**"——在缺陷检测中，这类问题目前几乎都是等到误检堆积才被发现的。

- **摘要**：视觉 Transformer 识别性能强，但算力、显存与能耗开销使其难以落到资源受限的工业现场；已有的效率手段——神经架构搜索、令牌压缩、低精度推理——大多**各优化一个轴**，单独用收益有限。本文提出一个把三条轴**联合优化**的整体框架：用 AutoFormer 做架构搜索找到紧凑骨干，用 ToMe 做令牌合并削减信息处理量，再用 fp16 混合精度加速单算子执行。作者先在 ImageNet-1K 上分析激进压缩下的精度-效率折衷，再把选出的配置迁移到一份真实的**内部 3D X 射线半导体缺陷分类数据集**（IC 芯片封装检测）上。结果是吞吐量提升 **10 倍以上**，同时参数量、FLOPs 与能耗均下降 **10 倍以上**，而下游工业任务所需精度得以保持。这是今日与"工业检测部署"最贴近的一篇：它给出的可迁移结论是，**架构 / 令牌 / 位宽三轴的收益近似可乘**，因此在边缘端做模型瘦身时不应只在单一轴上死磕。

`candidates.md` 因此写出「今日无匹配新论文」。**该行是网络故障的产物，不代表当日真的没有匹配论文**——替代通路已证伪（见下）。这是连续第三天出现同一故障（09-13、09-14 两期简报亦记录了 429/503 全败）。

**2）故障定位：不是出口策略拦截，是 arXiv 侧限流**

- `curl "$HTTPS_PROXY/__agentproxy/status"` 返回 `recentRelayFailures: []`，无出口策略拒绝记录；
- 直接 `curl https://export.arxiv.org/api/query?...` 拿到的是 **HTTP 429**（而非 403/407），说明 TCP/TLS 连接已建立、请求确实到达了 arXiv，是 arXiv 的 API 网关在限流；
- 结论：**环境已放行 export.arxiv.org，问题在数据源侧**，不是代理策略问题，无需调整出口配置。
- 另起后台任务以 60 秒间隔独立重试 API（纯 category 查询、只取 5 条，负载已降到最小），连续 7 次仍全部 429，至本简报写完时未恢复。

**3）替代通路：分类 RSS**

改走 `https://rss.arxiv.org/rss/<category>`，四个分类全部 200 正常返回，且 description 字段自带完整摘要原文：

| 分类 | lastBuildDate | 状态 |

| physics.optics | Mon, 14 Sep 2026 04:00:17 +0000 | 200 |
| eess.IV | Mon, 14 Sep 2026 04:00:29 +0000 | 200 |
| cs.CV | Mon, 14 Sep 2026 04:00:02 +0000 | 200 |
| eess.SP | Mon, 14 Sep 2026 04:00:05 +0000 | 200 |

复用 `fetch_arxiv.py` 的 `PROFILES["main"]["keywords"]`、`relevance_score()` 与 `load_past_reported_ids()` 三个函数原样打分去重，统计如下：

- 扫描公告条目 **212** 条 → ID 去重后 **207** 篇
- 命中历史简报已报道、跳过 **1** 篇
- 相关度得分 >0：**36** 篇 → 取前 **12** 篇入本简报

**4）与主通路的口径差异（需知悉）**

- RSS 只承载**最近一个公告批次**（2026-09-14 04:00 UTC），而脚本主通路是 72 小时滑动窗口，因此本期覆盖面**窄于**正常日；
- RSS 含 `replace` / `replace-cross` 类型的**修订重发**条目，而主通路按 `submittedDate` 排序 + 72h 窗口会把它们滤掉。本期第 6、8、12 篇即属此类（原始提交分别为 2026-06-25、2026-04-21、2026-05-03），已在各条目的日期栏显式标注，避免与真正的新投稿混淆；
- 本期所列相关度分值由同一套关键词表算出，与主通路口径一致，可与历史各期直接比较。

**5）建议**

若 429 在后续几期仍未消退，建议把 RSS 通路固化进 `fetch_arxiv.py`：作为 API 失败时的自动 fallback，并在窗口过滤处按 `arxiv_id` 前缀识别 `replace` 条目单独归类，以免长期靠人工补救。
